HOW IT WORKS

The Lottie Color Editor uses a layer-based approach for precise color editing. Upload your Lottie JSON file, select a layer from the panel, and edit its fill or stroke colors with live preview.

Controller Support: For animations using color controllers (like master color layers), the editor detects these automatically and lets you edit them directly. Changes propagate to all layers using that controller.
